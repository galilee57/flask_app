# Project styles

Project interfaces share the site's Tailwind v4 build. From the repository root:

```sh
npm run build:css
npm run watch:css
```

Use utility classes in Jinja templates for layout, spacing and responsive breakpoints. These component files are imported by the root `input.css`; use `@apply` for repeated controls, descendant rules and states generated by JavaScript. Keep selectors scoped to the project, especially when using generic names such as `panel` or `primary`. SVG painting and visualization geometry may remain CSS declarations.

Do not generate or load an additional Tailwind bundle in a project template. `base.html` loads `/static/css/output.css` for every project. Explicit source directories in `input.css` cover Jinja templates and controls generated by JavaScript or TypeScript. Rebuild after changing either kind of source.
