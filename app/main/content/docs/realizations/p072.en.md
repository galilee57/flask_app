# Develop an automatic industrial photo classification solution with AI Builder and Power Automate

*Lever artificial intelligence to classify product photos at the line entry and automate their processing.*

## Context

On an industrial production line, product photographs were available at the line entry.

These images constituted a usable information source to identify and classify products according to predefined categories.

Manual photo processing presented limitations regarding time, repeatability (influence of lighting and shooting conditions), and capacity to process a large volume of images.

I initiated a project aimed at using Microsoft Power Platform artificial intelligence technologies to automate this classification.

**The objective was to build an image classification model with AI Builder and integrate it into a Power Automate flow to process product photographs.**

## Objectives

- Exploit the photographs available at the line entry.
- Build a set of labeled images.
- Train a classification model with AI Builder.
- Automatically recognize defined categories.
- Integrate the model into an automated process with Power Automate.

## Approach and implementation

### 1. Define the classification need

I approached the project starting from the photographs available at the line entry and the product categories to identify.

The first step consisted of determining relevant classes and organizing the data necessary for learning.

This phase was essential: an artificial intelligence model can only produce usable results if categories are clearly defined and training examples are representative.

### 2. Prepare and label photographs

The project relied on building a set of photographs associated with their categories.

The labeling work provided the model with reference examples.

It notably required ensuring label consistency and image representativeness.

This step formed the foundation of supervised learning.

### 3. Build the model with AI Builder

I used Microsoft AI Builder to implement an image classification approach.

The model was tasked with learning to recognize defined categories from labeled photographs.

This solution enabled experimenting with visual intelligence within the Microsoft ecosystem, without fully developing a specific Machine Learning architecture.

The work involved configuring the model, providing it with training data, and examining its ability to differentiate classes.

### 4. Integrate classification into Power Automate

The project's value did not lie solely in creating an AI model.

It also involved integrating it into an automated process.

Power Automate enabled orchestrating the processing of photographs and invoking the AI Builder model.

This architecture combined visual recognition capabilities with a process automation tool.

### 5. Experiment with classification on line images

The solution was intended to classify photographs of products at the start of the line.

The experiment allowed examining the relevance of predictions and any potential limitations of the model.

Key areas of focus included image quality, distinction between categories, and the model's ability to handle situations different from those present in the training data.

## My Role

**I worked on implementing a visual AI solution combining image labeling, AI Builder, and Power Automate to classify industrial photographs.**

## Technologies and Methods

**Technologies:** Microsoft AI Builder, Power Automate, Microsoft Power Platform, image classification.

**Methods:** supervised learning, labeling, data preparation, automatic classification, workflow automation, industrial AI experimentation.

## Results

The project enabled classifying over 5000 images using the AI Builder model and Power Automate.

The result allowed defining the origin of marks regularly present on products, thereby reducing non-conformity.

## Lessons Learned

### Label quality determines model quality

Defining categories and ensuring consistency in training examples are essential for classification model performance.

### Low-Code tools facilitate experimentation

AI Builder and Power Automate enable rapid testing of AI use cases without developing the entire Machine Learning infrastructure.

**This project illustrates my ability to identify an industrial Computer Vision use case and leverage Microsoft Power Platform technologies to transform photographs into structured, automatable information.**
