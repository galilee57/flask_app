# Structurer, maintenir et versionner du code

**Volume de cours · 20 h.**

## Objectifs de la formation

Structurer les programmes, améliorer du code existant et suivre son évolution avec Git et GitHub.

## Déroulement

Le parcours associe les fondements de la programmation, les structures de données, la conception orientée objet et le refactoring à la gestion de versions. Programming Basics d’IITBombayX figure aussi dans mon inventaire edX.
