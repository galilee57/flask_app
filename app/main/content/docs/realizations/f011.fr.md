# Développer en Python pour le web et les données

**Volume de cours · 30 h.**

## Objectifs de la formation

Consolider les bases Python, exploiter des données et comprendre comment une application web expose ou consomme une API.

## Déroulement

Les cours parcourent les structures de données, la data science, le scripting, Flask et Django, puis les services web et les API REST. Algorithmic Trading with Python (Udemy) reste à démarrer.

- L’essentiel de Flask

- Les fondements de la programmation : Les services web et API
