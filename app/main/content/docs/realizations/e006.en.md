# Big Data Quality Support Manager

## Role and period

Since 2022, I have worked as **Big Data Quality Support Manager**. My role is to lead the big data initiative on behalf of the Quality function.

## Set business priorities

I identify the data the teams need and prioritise use cases based on industrial problems and expected benefits. I do this in coordination with IT and the Process teams at the sites.

## Data ingestion

Bringing data together in a data lake is a long-term effort. It requires ingesting data from multiple sources, each with its own constraints. I developed PySpark transformations and tools for this work, described in a separate project entry.

## Use cases

Analysis began while ingestion was still under way. Prioritising use cases made it possible to deliver early benefits, often by supplementing the data lake with data that had yet to be ingested.

## Governance

The current stage is to enrich and refine the data so each business team can use it more easily. A Data Mesh approach is under consideration.
