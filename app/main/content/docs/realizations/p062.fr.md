# Développer et distribuer une application Python de visualisation de la planéité industrielle

## A propos du projet

Sur une ligne industrielle, la planéité constitue une caractéristique importante pour le contrôle de la qualité.

Les données issues des équipements de mesure permettent de produire des cartographies représentant les variations de planéité sur la longueur et la largeur du produit.

Ces représentations sont particulièrement utiles pour identifier les zones présentant des écarts et faciliter l'interprétation des résultats par les équipes Qualité.

Cependant, l'outil historique de consultation ne permettait plus de restituer correctement certaines cartographies, notamment en raison de difficultés liées aux échelles de couleurs.

Une solution de remplacement avait été développée sous Excel, mais elle était devenue complexe à maintenir et peu adaptée à une utilisation interactive.

**J'ai donc développé une application Python dédiée, capable de générer des cartographies interactives et d'être distribuée sous forme d'exécutable Windows.**

## Objectifs

Le projet poursuivait plusieurs objectifs :

- Restaurer un accès fiable aux cartographies de planéité.
- Remplacer une solution Excel devenue difficile à maintenir.
- Proposer une visualisation interactive des données.
- Simplifier la mise à disposition de l'application.
- Éviter toute installation préalable d'un environnement Python sur les postes utilisateurs.
- Limiter les besoins d'infrastructure et de maintenance informatique.

## Démarche

### 1. Analyser le besoin métier et les limites de l'existant

La première étape a consisté à comprendre les difficultés rencontrées avec les outils de consultation existants.

L'objectif n'était pas simplement de reproduire un graphique, mais de rendre les données interprétables dans un contexte industriel.

### 2. Développer une chaîne de traitement en Python

J'ai conçu une application permettant de rechercher, charger et transformer les données nécessaires à la construction des cartographies.

Le traitement repose sur Python pour organiser les données sous une forme exploitable par le moteur de visualisation.

L'application peut parcourir automatiquement un répertoire de données ainsi que ses sous-répertoires afin d'identifier les fichiers disponibles.

### 3. Créer des cartographies interactives avec Plotly

J'ai utilisé la bibliothèque Plotly pour produire les visualisations.

Ce choix permet de bénéficier de fonctionnalités interactives sans devoir développer un moteur graphique spécifique.

Les utilisateurs disposent notamment de :

- Zoom sur les zones de la cartographie.
- Déplacement dans la représentation.
- Consultation des valeurs au survol.
- Adaptation de l'affichage.
- Export de la cartographie sous forme d'image.

La visualisation est ouverte dans un navigateur, qui sert d'interface graphique à l'application.

**Cette architecture associe la puissance de traitement de Python à l'interactivité des technologies web, sans nécessiter le déploiement d'un serveur applicatif central.**

### 4. Transformer l'application Python en exécutable avec PyInstaller

L'un des principaux défis consistait à rendre l'outil accessible à des utilisateurs ne disposant pas d'un environnement de développement.

J'ai utilisé **PyInstaller** pour empaqueter l'application Python et ses dépendances dans un exécutable Windows.

Cette solution permet de distribuer l'outil sans demander aux utilisateurs d'installer Python ou les bibliothèques nécessaires.

Elle évite également de devoir maintenir individuellement des environnements Python sur les postes de travail.

**Le passage du script à l'exécutable constitue une étape essentielle : l'application devient un outil métier directement utilisable, et non plus un programme réservé aux développeurs.**

### 6. Organiser la distribution avec SharePoint

Pour faciliter l'accès à l'application et aux données, j'ai retenu une solution reposant sur SharePoint et la synchronisation locale.

Les fichiers nécessaires sont mis à disposition dans un espace partagé, synchronisé sur les postes concernés.

L'application peut alors exploiter les fichiers présents dans le répertoire local synchronisé.

Le dispositif repose sur une architecture légère, adaptée à un besoin ciblé.

## Mon rôle

**J'ai conçu et développé l'application Python, réalisé son empaquetage avec PyInstaller et défini son mode de distribution aux utilisateurs.**

Ce projet mobilise à la fois mes compétences de développeur Python, ma connaissance des données industrielles et ma capacité à concevoir des outils adaptés aux utilisateurs métier.

## Résultats

**Une application Python de visualisation de la planéité, empaquetée en exécutable Windows et conçue pour être accessible sans installation d'un environnement Python.**

## Enseignements

**Une application métier efficace n'a pas nécessairement besoin d'une architecture lourde ou d'une infrastructure web centralisée.**

**Choisir une architecture proportionnée au besoin.** Une application locale utilisant un navigateur peut répondre efficacement à des exigences de visualisation interactive.

**Transformer un script en produit utilisable.** PyInstaller permet de franchir une étape importante entre développement Python et diffusion d'un outil métier.

**Penser à l'utilisateur final dès la conception.** La facilité d'accès, l'interactivité et la simplicité d'utilisation déterminent l'intérêt opérationnel d'une application.

**Ce projet démontre ma capacité à développer une application Python de bout en bout, depuis le traitement des données industrielles jusqu'à sa distribution sous forme d'exécutable autonome, avec une architecture légère et orientée utilisateur.**
