# Big Data Quality Support Manager

## Role

Since 2022, I have led the **big data initiative for the Quality function**. I define business needs and prioritise use cases with IT and site Process teams.

## Ingestion, use cases and governance

I developed PySpark transformations to ingest and prepare data from several sources in a data lake. Early use cases progressed during ingestion, using external data where needed. The current stage focuses on data enrichment and governance, with a Data Mesh approach under consideration.
