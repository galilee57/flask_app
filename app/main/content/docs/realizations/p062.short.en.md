## The project

Replace a complex Excel tool with an interactive, standalone, and easily distributable application using PyInstaller.

## My contribution

**I designed and developed the Python application, performed its packaging with PyInstaller, and defined its distribution mode for users.**

This project mobilizes both my Python development skills, my knowledge of industrial data, and my ability to design tools adapted for business users.

## Results

**A Python visualization application for flatness, packaged as a Windows executable and designed to be accessible without installing a Python environment.**
