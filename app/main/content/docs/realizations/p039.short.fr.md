## Le projet

Utiliser les cocepts de séparation de code et de responsabilités avec les outils Microsoft

## Ma contribution

J'ai assuré la conception de l'architecture générique, le développement des traitements Power Query et leur documentation.

J'ai également participé à l'exploitation opérationnelle des rapports, depuis la résolution des problèmes de données jusqu'à leur remise à disposition sur Power BI Service.

## Résultats

- Développement d'un modèle générique et configurable pour les analyses de capabilité.

- Mutualisation des traitements Power Query entre différents contextes industriels.
