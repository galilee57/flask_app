# Develop and distribute a Python application for industrial flatness visualization

## About the Project

On an industrial line, flatness is a key characteristic for quality control.

Data from measurement equipment enables the production of maps representing flatness variations along the product's length and width.

These representations are particularly useful for identifying areas with deviations and facilitating result interpretation by Quality teams.

However, the historical consultation tool could no longer correctly display certain maps, notably due to issues related to color scales.

A replacement solution had been developed in Excel, but it had become complex to maintain and poorly suited for interactive use.

**I therefore developed a dedicated Python application capable of generating interactive maps and being distributed as a Windows executable.**

## Objectives

The project pursued several objectives:

- Restore reliable access to flatness maps.
- Replace an Excel solution that had become difficult to maintain.
- Propose interactive data visualization.
- Simplify the application's availability.
- Avoid any prior installation of a Python environment on user workstations.
- Limit infrastructure and IT maintenance requirements.

## Approach

### 1. Analyze business needs and existing limitations

The first step consisted of understanding the difficulties encountered with existing consultation tools.

The goal was not simply to reproduce a chart, but to make data interpretable in an industrial context.

### 2. Develop a Python processing chain

I designed an application allowing the search, loading, and transformation of data necessary for building the maps.

The processing relies on Python to organize data in a form exploitable by the visualization engine.

The application can automatically browse a data directory and its subdirectories to identify available files.

### 3. Create interactive maps with Plotly

I used the Plotly library to produce the visualizations.

This choice allows leveraging interactive features without having to develop a specific graphics engine.

Users have access to:

- Zoom on areas of the map.
- Navigation within the representation.
- Viewing values on hover.
- Display adaptation.
- Exporting the map as an image.

The visualization is opened in a browser, which serves as the graphical interface for the application.

**This architecture combines the processing power of Python with the interactivity of web technologies, without requiring the deployment of a central application server.**

### 4. Transform the Python application into an executable with PyInstaller

One of the main challenges was making the tool accessible to users who do not have a development environment.

I used **PyInstaller** to package the Python application and its dependencies into a Windows executable.

This solution allows distributing the tool without requiring users to install Python or the necessary libraries.

It also avoids having to maintain individual Python environments on workstations.

**The transition from script to executable is an essential step: the application becomes a business tool directly usable, rather than a program reserved for developers.**

### 6. Organize distribution with SharePoint

To facilitate access to the application and data, I chose a solution based on SharePoint and local synchronization.

The necessary files are made available in a shared space synchronized on the concerned workstations.

The application can then exploit the files present in the synchronized local directory.

The setup relies on a lightweight architecture, adapted to a targeted need.

## My Role

**I designed and developed the Python application, performed its packaging with PyInstaller, and defined its distribution mode for users.**

This project mobilizes both my Python development skills, my knowledge of industrial data, and my ability to design tools adapted for business users.

## Results

**A Python visualization application for flatness, packaged as a Windows executable and designed to be accessible without installing a Python environment.**

## Lessons Learned

**An effective business application does not necessarily require a heavy architecture or a centralized web infrastructure.**

**Choose an architecture proportional to the need.** A local application using a browser can effectively meet interactive visualization requirements.

**Transform a script into a usable product.** PyInstaller enables an important step between Python development and the distribution of a business tool.

**Think about the end-user from the design stage.** Ease of access, interactivity, and ease of use determine the operational value of an application.

**This project demonstrates my ability to develop a Python application from end to end, from processing industrial data to distributing it as a standalone executable, with a lightweight and user-oriented architecture.**
