# Graph sources

These six datasets are unmodified copies of `Shortest_Path/datasets` from
https://github.com/iridia-ulb/AI-book (retrieved 2026-10-04).
Copyright (c) 2021 IRIDIA, ULB. MIT license: see LICENSE.

The Flask search engine and browser UI are a new implementation. Unlike the
original loader, edge lengths are not rounded before searching; only displayed
values are rounded. This preserves admissibility of the Euclidean heuristic.
